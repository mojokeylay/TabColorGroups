# Change Log

All notable changes to the "tab-color-groups" extension will be documented in this file.

## [1.1.0] - 2026-10-15
## Added
- Group Reordering: You can now drag and drop entire tab groups in the sidebar to reorder them.
- Move Up/Down Buttons: Added inline arrow buttons next to group names for quick and easy group reordering.
