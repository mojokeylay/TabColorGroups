# Tab Color Groups

A Visual Studio Code extension to easily organize and color-code your editor tabs into custom groups for cleaner workspace navigation.

![Preview](images/preview.png)

## Features

- **Custom Colors:** Highlight and tint editor tabs using customizable color presets.
- **Group Organization:** Keep related files grouped visually.
- **Persistent State:** Saves group associations across workspace sessions.

## Usage

1. Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`).
2. Run `Tab Color Groups: Set Group Color`.
3. Pick a color palette to tint the active tab.

## Extension Settings

This extension contributes the following settings:

* `tabColorGroups.enable`: Enable or disable the extension.
